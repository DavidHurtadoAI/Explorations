# Explorations

Explorations on AI, nothing too techie.

Colección de páginas HTML autocontenidas —guías, simuladores, mapas visuales y experimentos— publicadas con GitHub Pages. Cada archivo funciona por sí solo: se abre en el navegador o se embebe donde haga falta.

**Índice:** 40 páginas · <a href="https://davidhurtadoai.github.io/Explorations/" target="_blank" rel="noopener noreferrer">ver el sitio</a>

## Cómo usarlas

Abrir directamente en el navegador:

```
https://davidhurtadoai.github.io/Explorations/<archivo>.html
```

Embeber en una nota de Obsidian (o en cualquier HTML) con un iFrame:

```html
<iframe src="https://davidhurtadoai.github.io/Explorations/outlook-tetris.html" width="600" height="810" style="border:none;"></iframe>
```
